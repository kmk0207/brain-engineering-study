# Signal Processing Roadmap

## 학습 목표

EEG 신호를 시간 영역과 주파수 영역에서 이해하고, filtering과 PSD 분석으로 연결한다.

- [STEP 19. Power Spectral Density](./step-19-power-spectral-density/readme.md)

## 완료 기준

- Sampling rate와 Nyquist frequency를 설명할 수 있다.
- 시간 신호를 주파수 성분으로 바꾸는 이유를 이해한다.
- EEG filtering과 PSD가 band power feature로 이어지는 흐름을 설명할 수 있다.
