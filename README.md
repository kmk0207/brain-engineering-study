# Brain Engineering Study

Python, Machine Learning, Signal Processing, Neuroscience & EEG를 하나의 흐름으로 공부하기 위한 작업 폴더입니다.

## 전체 학습 목표

- Python으로 EEG 형태의 수치 데이터를 직접 다룰 수 있다.
- Machine Learning의 기본 구조를 이해하고 EEG feature를 이용한 분류 모델을 구현할 수 있다.
- Signal Processing의 핵심 개념을 익혀 EEG preprocessing과 feature extraction으로 연결할 수 있다.
- Neuroscience와 EEG 기초를 이해하고 인지 상태 분석 연구 질문으로 확장할 수 있다.
