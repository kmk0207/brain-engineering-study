## 완료 기준

- 다른 사람의 Python 코드를 읽고 간단히 수정할 수 있다.
- `EEG[channel, time]` 형태의 데이터를 선택하고 계산할 수 있다.
- 실험 참가자 정보와 label을 표 형태로 관리할 수 있다.
- 시간-domain EEG signal을 직접 그래프로 표현할 수 있다.
